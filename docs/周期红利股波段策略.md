### 1.2 定位（与A类的本质区别）

- **B类=披着红利皮的周期股**：股息是缓冲垫不是免疫；周线级回撤（如煤炭2024年-20%段）股息扛不住
- **A类（银行23+公用+出版约50只）＝拿息不动**；**B类＝唯一值得做波段+T的子类**
- 做T适配度量化（2026-08-25盘中）：流动性60%+振幅40%加权，Top12全部为周期红利票；银行/水泥振幅<1.5%不适合T

## 三、大盘×板块四象限操作地图（核心）

| | 板块5日流入 | 板块5日流出 |
|---|---|---|
| **大盘强** | ① 主升浪：满配吃鱼身 | ② 资金被抽走：反弹减仓 |
| **大盘弱** | ③ 避险抱团最肥段：持有+回踩加 | ④ 双杀：清到只剩底仓 |

- **2026-08-25状态：③尾段向②切换**——5日资源仍流入(+130.1亿)但当日资金归零转投成长(+136亿)，风格得分 进攻69.5/周期5.0
- **切换判定**：
  - 预警级 = 当日风格得分周期<10 且当日资金被成长抽走 → 停止新开仓、急拉兑现
  - 确认级 = 所持分支5日主力资金转负 → 降半仓；两个以上分支同时转负 → 只留底仓
- 单日不算数：板块5日资金连续3~5日才定性（祖训：单日不定性）

## 五、入场规则（门控放行后分批进介入区）

1. **门控一票否决**：position_sizer 放行才动手（F档=总仓0%，纯预案；放行=放量收复MA20并站稳）
2. **位置**：只在 entry_point.py 输出的介入区挂单，区外不追——吃鱼身的执行化（放弃鱼头、不追鱼尾）
3. **分批**：首批1/2仓介入区上沿试错；缩量回踩至下沿(MA10±3%)补足剩余。禁止一次打满
4. **确认信号**：买"回踩后第一根缩量企稳阳"——当日量比<1 + 价格站回介入区，缺一不可；不接正在下跌的刀

## 六、离场四出口（触发即走，不商量）

| 出口 | 触发条件 | 动作 |
|---|---|---|
| 止损 | 收盘跌破工具止损位(≈MA10×0.95) 或 -5% | 无条件清，不补仓不摊平 |
| 止盈 | 距MA10>8% 或 RSI>70 急拉段 | 分批减1/2~2/3，留底仓吃息 |
| 板块转流出 | 所持分支5日资金转负 | 降半仓；两分支同转负→只留底仓 |
| 时间止损 | 入场5日横盘跑输分支指数 | 换第一梯队更强标的 |

- **除息特例**：分红除权跳低不是破位（前复权K线已含该因素）；真正该走=除息后连续放量不填权

## 七、吃哪段：鱼身为主菜

- **鱼头（左侧摸底）不吃**：冰点不抄底、未测试不做左侧——F档规则防的就是它
- **鱼身（主升确认段）主吃**：起点=放量确认+Q≥80回踩+板块资金流入；脊骨=MA10上方持有，缩量回踩加/放量破位走
- **鱼尾（加速赶顶）不吃只减**：距MA10>8%+RSI超买+放量滞涨=分批兑现；空仓者看着
- **B类特性**：鱼身比科技主线短且颠——沿MA10小网格滚动（回踩加/急拉减），吃到六七成即满分
- 教科书案例（2026-08-25）：中谷物流前期拉至距MA10+8.4%（鱼尾形态），次日-7.32%放巨量——追高者当场被套
