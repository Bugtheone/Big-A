# 运维与调度手册

> 收盘后每日流水线的部署 / 调度 / 回滚说明。本文档是生产调度的唯一事实来源（single source of truth）。

## 一、每日流水线

`scripts/tools/run_daily_job.py` 是本仓库的生产调度入口，收盘后依次执行：

1. **每日复盘 v2** `scripts/analysis/daily/_daily_review_v2.py` — 多源交叉验证 + 全市场复盘，报告输出到 `reports/`
2. **飞书日报推送** `scripts/tools/daily_feishu_report.py` — 大盘/涨停/热门板块/成交额推送到飞书机器人（需 `config/feishu_config.json` 配置 webhook）

任一步失败不阻断后续步骤；**退出码 = 失败步骤数**（0 表示全部成功）。

## 二、crontab 配置

### 线上配置（2026-08-02 起，已切换为本仓库入口）

```cron
0 18 * * 1-5 cd /home/dev/grok_code && /home/dev/miniforge3/envs/dsa_env/bin/python scripts/tools/run_daily_job.py >> /home/dev/grok_code/log/daily_job.log 2>&1
```

### 历史配置（2026-08-02 前）


> 旧行调度的是**独立项目** `/home/dev/daily_stock_analysis`（自选股智能分析系统，自有 git 仓库 v3.28.0）的 `main.py`，与本仓库无关；已切换为本仓库流水线。如需恢复，见下方回滚。

### 切换 / 回滚步骤

```bash
# 1. 查看当前 crontab
crontab -l

# 2. 切换前的备份文件（2026-08-02 已生成）
ls /tmp/crontab.bak.*

# 3. 手动切换：crontab -e，替换为「线上配置」行

# 4. 验证：下一次触发后查看日志
tail -f /home/dev/grok_code/log/daily_job.log

# 5. 回滚：恢复备份（含切换前的 daily_stock_analysis 调度）
crontab /tmp/crontab.bak.2026-08-02
```

## 四、监控与告警

- **日志**：`log/daily_job.log`（crontab 重定向），每步含耗时与 OK/FAIL 标记
- **失败检测**：退出码非 0 即失败；可在 crontab 行尾追加 `|| 通知命令`（如飞书告警）实现失败即通知
- **数据质量**：`data_gate` 审计轨迹（字段级 + 跨源验证）内置于每次数据访问，异常自动记录

## 五、环境依赖

- Python：`/home/dev/miniforge3/envs/dsa_env`（含 pandas/requests/mootdx 等运行依赖）
- 密钥：`config/` 不入库，飞书 webhook 在 `config/feishu_config.json`，API Key 走环境变量（`IWENCAI_API_KEY`）
- 新机器部署：`pip install -r requirements.txt -r requirements-dev.txt`
