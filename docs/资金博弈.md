## 一、资金博弈三种模式（最高层判断）

| 模式 | 特征 | 市场表现 | 玩法 |
|---|---|---|---|
| **增量博弈** | 新钱入场（牛市）| 普涨、量持续放大、主线扩散 | 满仓持有主线 |
| **存量博弈** | 钱不增不减（震荡）| **跷跷板轮动**、量能恒定 | 高抛低吸轮动 |
| **减量博弈** | 钱在撤（熊市）| 普跌、量萎缩、抱团最后瓦解 | 空仓避险 |

### 判定指标（用数据说话）

```
成交量：持续 >2.5万亿 = 增量 · 1.5~2.5万亿 = 存量 · <1.5万亿 = 减量
（今日 08-06：25475亿 = 增量/存量临界上沿）
广度：>60% 普涨 = 增量 · 40~60% 轮动 = 存量 · <40% 普跌 = 减量
两融/北向：持续净流入 = 增量 · 平衡 = 存量 · 净流出 = 减量
```

## 二、存量资金博弈详解（本体系核心）

### 2.1 存量博弈的本质

```
池子里的水不增不减 → 板块A涨的钱来自板块B
= 板块轮动（跷跷板）→ 无普涨 → 主线切换频繁
```

### 2.2 存量博弈的五大特征

| 特征 | 表现 | 识别 |
|---|---|---|
| ① 跷跷板轮动 | 科技涨→消费跌；周期涨→科技跌 | 板块资金此消彼长 |
| ② 量能恒定 | 总量维持 1.5~2.5万亿 | 无持续放大 |
| ③ 主线切换快 | 热点 3-5 天轮换 | 涨停题材榜变化 |
| ④ 抱团极端化 | 资金挤向少数方向 | 广度低+指数稳 |
| ⑤ 情绪周期短 | 恐慌→修复循环频繁 | 广度大幅波动 |

### 2.3 存量博弈的轮动规律（A股经典轮动链）

```
大盘蓝筹 ⇄ 中小题材（市值轮动）
科技成长 ⇄ 消费防御（风格轮动）
周期资源 ⇄ 黄金避险（风险偏好轮动）
高位热点 ⇄ 低位补涨（高低切）
```

**轮动节奏**：一般 3-5 天一轮 → **追热点需在第 1-2 天，第 3 天起随时切换**（对应交易哲学"只做持续分支"）

## 三、资金博弈参与主体（七路资金）

| 资金类型 | 属性 | 特点 | 观察指标 |
|---|---|---|---|
| **公募基金** | 机构 | 重仓核心资产，季报调仓 | 持仓披露 |
| **私募游资** | 短线 | 打板/连板，情绪主导 | 龙虎榜/涨停池 |
| **北向资金** | 外资 | 偏好核心资产，风向标 | 北向净买入 |
| **两融资金** | 杠杆 | 助涨助跌，散户情绪 | 融资余额 |
| **ETF资金** | 配置 | 被动买入，增量通道 | ETF份额 |
| **产业资本** | 实业 | 增减持/回购 | 股东增减持 |
| **散户** | 个体 | 追涨杀跌，情绪反向 | 开户数/交易活跃度 |

### 存量博弈下七路资金的关系

```
公募（调仓）→ 决定核心资产方向
游资（打板）→ 决定题材情绪高度
北向（配置）→ 决定大盘权重方向
两融（杠杆）→ 放大波动
散户（跟风）→ 情绪反向指标（开户潮=见顶）
```

## 五、存量博弈的操作策略（对应策略分类）

| 资金模式 | 策略 | 仓位 | 纪律 |
|---|---|---|---|
| **存量**（当前常态）| 轮动高抛低吸 · 主线回踩介入 | ≤50% | 不追高 · 及时止盈 |
| **增量**（牛市）| 趋势跟踪持有主线 | 70~100% | 让利润奔跑 |
| **减量**（熊市）| 空仓/防御红利 | ≤20% | 止损坚决 |

### 存量博弈下具体打法（本轮 08-04~08-06 验证）

```
✅ 主线回踩介入（有性价比）：Q-score ≥80 真回踩（茅台 92）
✅ 高低切换（轮动核心）：资金从防御切科技（8/4-8/6 科技反攻）
✅ 只做持续分支（3-5日）：电子链 5 日资金 +141亿
❌ 追高热点（无性价比）：急拉超买 Q<50（富联/胜宏 44）
❌ 满仓单一方向（轮动风险）：跷跷板会打脸
```

## 六、存量/增量/减量切换信号

### 存量 → 增量（转牛）

```
✅ 成交连续 5 日 >2.5万亿
✅ 广度稳定 >60%（普涨）
✅ 主线扩散（从单一科技到多方向）
✅ 两融/北向持续净流入
```

### 存量 → 减量（转熊）

```
🔴 成交萎缩至 <1.5万亿
🔴 广度持续 <40%（普跌）
🔴 抱团瓦解（主线资金大幅流出）
🔴 炸板率 >25% + 涨停 <60
```

### 当前状态判定（08-06 数据）

```
成交 25475亿（>2.5万亿 = 增量临界上沿）
广度 51.8%（存量区间）
涨停 112（情绪活跃）
→ 判定：存量博弈偏增量（转牛临界），需连续验证
```
