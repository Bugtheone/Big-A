## 1. 项目概述

一个**全栈A股量化分析工作台**，集数据获取、交叉验证、策略筛选、每日复盘和飞书推送于一体。

### 核心能力

| 能力 | 说明 |
|------|------|
| **行情数据** | 九大指数实时/历史K线、全市场个股行情、行业板块排名 |
| **资金面** | 北向资金、板块资金流向（行业/概念/地域 × 今日/5日/10日） |
| **打板情绪** | 涨停池、炸板池、跌停池、高标连板、炸板率统计 |
| **新闻舆情** | 财联社7×24实时电报 |
| **基本面** | Tushare.pro 财务数据、指数成份股权重 |
| **策略分析** | DKX金叉选股、波段筛选、止跌确认五层框架 |
| **每日报告** | 收盘复盘 → Markdown报告 + 飞书推送 |
| **数据验证** | 全项目数据守门员自动字段验证 + 跨源交叉验证 |

### 数据流

```
腾讯API ─────┐
东财API ─────┤
Tushare ─────┼──→ DataGate(守门员) ──→ 验证后的数据 ──→ 脚本/报告
财联社 ──────┤
mootdx ──────┘          ↓
                   跨源交叉验证
                   (北向/涨停/指数)
```

## 2. 环境搭建

### 2.1 安装 Python 依赖

```bash
pip install -r requirements.txt
```

核心依赖：
- `requests` / `pandas` / `numpy` — 基础数据处理
- `mootdx` — 通达信行情（优先数据源）
- `tushare` — Tushare.pro 基本面/指数权重
- `stockstats` — 技术指标计算
- `pytest` — 单元测试
- `iwencai-skillhub-cli` — 同花顺AI技能CLI

### 2.2 配置 Tushare（可选）

编辑 `config/tushare_config.json`，填入你的 Tushare token：

```json
{
  "token": "你的token",
  "timeout": 30,
  "retry_count": 3
}
```

> Token 在 [tushare.pro](https://tushare.pro) 注册免费获取。不配置不影响使用，只是不能调用 Tushare 相关功能。

### 2.3 配置 iwencai SkillHub（可选）

```powershell
setx IWENCAI_API_KEY "你的key"
```

> 用于语义搜索和AI选股，不影响日常行情数据使用。

### 2.4 验证安装

```bash
# 测试核心API
python tests/test_core_functions.py -v

# 测试Tushare连接
python scripts/tushare_fetch.py --test
```

## 4. 数据源体系

### 4.1 三大主数据源

| 数据源 | 入口函数 | 优势 | 限制 |
|--------|----------|------|------|
| **腾讯** | `get_tencent()` | 不封IP、速度快、免费 | 仅行情/板块 |
| **东方财富** | `get_eastmoney()` | 打板/北向/资金流向 | 需限流(0.5s/次) |
| **Tushare** | `get_pro()` | 基本面/指数权重 | Token免费但有频次限制 |

### 4.2 数据守门员（DataGate）

**所有脚本的数据访问必须走 DataGate**，它会自动：

1. **字段验证** — 价格范围、成交量、OHLC逻辑、北向金额等
2. **跨源交叉验证** — 同一数据比对腾讯 vs 东财 vs Tushare
3. **零值陷阱诊断** — 自动检测 API 返回全0的异常情况
4. **审计轨迹** — 五级（OK/INFO/WARN/FAIL/CROSS）+ Markdown报告

```python
from scripts.data_gate import gate

# 使用守门员获取数据（替代直接调用API）
indices = gate.tc_indices()           # 九大指数
kline = gate.tc_kline('000001', 30)   # 日K线
turnover = gate.tc_turnover()         # 成交额
sectors = gate.tc_sectors(10)         # 板块排名
north = gate.em_north_flow(3)         # 北向资金
board = gate.em_board_summary()       # 打板汇总

# 任务结束后检查验证结果
gate.print_audit()
```

## 6. 核心脚本详解

### 6.1 `_daily_review.py` — 每日收盘复盘 ⭐

**最常用的脚本，每日必跑。**

输出内容：
- 九大指数收盘价与涨跌幅
- 行业板块涨幅 TOP5
- 涨停情绪（涨停数/跌停数/炸板率/最高连板）
- 北向资金（Tushare + 东财 交叉验证）
- 数据健康度评分

```bash
python scripts/_daily_review.py
# 报告自动写入 log/YYYYMMDD_收盘复盘.md
```

### 6.2 `_stop_falling_check.py` — 止跌确认五层框架

判断市场是否真正止跌，不是看一天。

五层信号：
1. **价格结构** — 不创新低 + 站上MA5 + 高低点上移
2. **量价配合** — 缩量止跌 + 放量反弹 + 量价同步
3. **广度确认** — 涨停情绪 + 大小盘剪刀差
4. **资金面** — 北向连续净流入
5. **均线系统** — MA5金叉MA10 + 波动率下降

```bash
python scripts/_stop_falling_check.py
# 输出五层逐项打分 + 综合判定
```

### 6.3 `_market_30d_analysis.py` — 30日大盘全景

拉取八大指数最近30个交易日的K线，分析：
- 各指数涨跌幅、阴阳比、年化波动率
- 三段式演变（前/中/后各10天）
- 前15日 vs 后15日 反转程度
- 极端行情日统计

```bash
python scripts/_market_30d_analysis.py
```

### 6.4 DKX 金叉系列

| 脚本 | 功能 |
|------|------|
| `_dkx_full_rank.py` | 全量金叉股综合排名（MA结构+振幅+量比+距支撑） |
| `_dkx_cross_check.py` | 交叉验证（涨停+主线板块+资金流向） |
| `_dkx_entry_confirm.py` | 介入点→确定点框架（金叉日→回踩MA20确认） |
| `_quick_check.py` | 个股快速状态检查 |

### 6.5 `_swing_screener.py` — 波段选股筛选器

从涨停池 + 主线板块初选，逐只计算：
- 均线排列评分
- 平均振幅
- 量比
- 距MA20支撑位距离

按评分排序，输出适合当前市场阶段的候选标的。

### 6.6 飞书推送

```bash
# 推送到飞书群
python scripts/tools/daily_feishu_report.py
```

配置飞书 Webhook URL 在 `config/feishu_config.json` 中编辑。

## 7. 策略分析框架

### 7.1 DKX 金叉 → 确定点流程

```
金叉日（介入点）
    ↓
观察期（1-10天）
    ↓ 条件：回踩MA20 + 量能确认 + 不破金叉日低点
确定点（买入窗口）
    ↓
持有 → MA10止盈 / 破MA20止损
```

### 7.2 波段交易规则

**入场**：月线大跌后 + 上证 > 创业板 + 恐慌信号 + 大长腿K线
**出场**：月线大涨后 + 创业板 > 上证 + 贪婪信号 + 缩量上涨
**仓位**：赚钱效应好=重仓 / 横盘=半仓 / 亏钱效应=轻仓

### 7.3 仓位模型

| 月线阶段 | A类(成长) | B类(价值) | C类(现金) | 总仓位 |
|----------|-----------|-----------|-----------|--------|
| 大跌月(<-5%) | 15% | 15% | 70% | 30% |
| 弱反弹(0-3%) | 20% | 25% | 55% | 45% |
| 主升(>3%) | 40% | 30% | 30% | 70% |
| 冲顶(>5%) | 20% | 10% | 70% | 30% |
| 震荡 | 20% | 30% | 50% | 50% |

### 7.4 止跌五层确认（详见 §6.2）

只有当五层信号中至少 4 层通过（得分 ≥60%），才能初步确认止跌。

## 10. 注意事项

### 编码规范

- 所有 HTTP 请求必须设置 `Session().trust_env = False`
- 禁止裸 `except:`，必须写具体异常类型
- 所有可执行脚本必须加 `if __name__ == '__main__':` 保护
- 禁止硬编码路径，使用 `BASE_DIR` 计算相对路径

### 数据源限制

| 限制 | 说明 |
|------|------|
| 东财限流 | `push2` 接口内置 0.5s/次冷却，盘前/节假日返回 rc=102 属正常 |
| Tushare频次 | 免费用户有调用次数限制，不建议高频批量拉取 |
| 腾讯编码 | 返回 GBK 编码，需 `.decode('gbk', errors='replace')` |
| iwencai | 需要 API Key，已通过环境变量持久化 |

### 常见问题

**Q: 脚本报 `ImportError`？**
A: 确保 `cd` 到项目根目录运行，或设置 `PYTHONPATH`。

**Q: 东财涨停数据为空？**
A: 盘中/节假日东财 push2 接口返回 rc=102 是正常的，收盘后再跑。

**Q: 北向数据显示 0？**
A: 东财延迟数据有时为 0，DataGate 会自动标注 CROSS 并建议用 Tushare 数据。

**Q: 如何添加新的数据源？**
A: 参考 `tencent_api.py` 的单例模式，创建新 API 类，在 `data_gate.py` 中注册入口即可。
