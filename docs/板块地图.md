```
A股市场
  │
  ├─ ① 科技成长（进攻核心）
  ├─ ② 大消费（防御+成长混合）
```

## 二、六大方向详解（含细分板块）

### ① 科技成长 —— 进攻核心（高贝塔）

| 细分 | 代表板块/概念 | 风格 |
|---|---|---|
| **AI 算力** | CPO/光模块/服务器/算力租赁 | 🟢 进攻 |
| **半导体** | 半导体设备/材料/封测/设计/存储 | 🟢 进攻 |
| **电子** | PCB/元件/消费电子/光学 | 🟢 进攻 |
| **通信** | 5G/6G/通信设备/光通信 | 🟢 进攻 |
| **计算机/软件** | 信创/人工智能应用/AI软件 | 🟢 进攻 |
| **军工** | 国防军工/商业航天/大飞机 | 🟡 进攻+事件 |

**特征**：高弹性、高波动、强主题驱动；市场上涨时领涨，下跌时领跌
**交易哲学映射**：主线五条件（涨幅/资金/涨停/连板/逻辑）主要在此大类内

### ② 大消费 —— 防御+成长混合（稳定现金流）

| 细分 | 代表板块 | 风格 |
|---|---|---|
| **白酒** | 贵州茅台/五粮液 | 🟢 防御核心 |
| **食品饮料** | 乳制品/调味品/饮料 | 🟢 防御 |
| **医药** | 创新药/中药/医疗器械/医药商业 | 🟢 防御+成长 |
| **家电** | 白电/厨电/小家电 | 🟢 防御 |
| **免税/旅游** | 中国中免/酒店/景区 | 🟡 复苏（周期防御）|
| **农业** | 种植/养殖/种业 | 🟡 周期防御 |

**特征**：业绩确定性高、现金流稳定、弱周期；机构底仓首选

### ③ 大金融 —— 防御+顺周期混合（低估值）

| 细分 | 代表板块 | 风格 |
|---|---|---|
| **银行** | 国有大行/股份行/城商行 | 🟢 纯防御（红利）|
| **保险** | 寿险/财险 | 🟢 防御 |
| **证券** | 券商/投行 | 🟡 顺周期（牛市旗手）|
| **多元金融** | 信托/租赁/期货 | 🟡 顺周期 |

**特征**：估值低、股息率高、与利率/经济周期相关；**证券是牛熊风向标**（进攻属性在牛市显现）

### ④ 大周期 —— 强周期（商品/制造）

| 细分 | 代表板块 | 风格 |
|---|---|---|
| **能源资源** | 煤炭/石油/天然气 | 🔵 周期（+防御红利属性）|
| **有色金属** | 铜/铝/黄金/稀土/锂 | 🔵 周期（黄金=避险）|
| **钢铁/建材** | 钢/水泥/玻璃 | 🔵 周期 |
| **化工** | 基础化工/化纤/农化 | 🔵 周期 |
| **机械** | 工程机械/专用设备 | 🔵 周期 |
| **交运** | 航运/港口/物流 | 🔵 周期 |

**特征**：与全球商品价格/宏观周期强相关；PPI/PMI 先行指标

### ⑤ 公共事业/红利 —— 纯防御（类固收）

| 细分 | 代表板块 | 风格 |
|---|---|---|
| **电力** | 火电/水电/核电/绿电 | 🟢 纯防御 |
| **公用事业** | 燃气/水务/环保 | 🟢 纯防御 |
| **高股息** | 中字头/破净股/红利ETF成分 | 🟢 纯防御 |

**特征**：低波动、稳定分红、利率下行受益；市场最弱时的"避风港"

### ⑥ 题材/主题 —— 游资/事件驱动（风格不定）

| 细分 | 代表 | 风格 |
|---|---|---|
| **政策题材** | 国企改革/一带一路/数字经济 | 🟡 事件 |
| **产业题材** | 固态电池/机器人/低空经济/虚拟现实 | 🟡 事件 |
| **事件题材** | 中报预增/重组/龙虎榜 | 🟡 事件 |

**特征**：快进快出、连板效应、情绪驱动；**只做有延续性（连续3日）的题材**

### 风格切换逻辑（style_forecast 三维）

```

周期（资源）得分高 → 做煤炭/有色/化工（商品牛）
```

## 四、风格轮动规律（A股经验法则）

### 大类轮动（存量博弈下）

```
进攻强（科技） → 防御弱（银行/白酒回调）→ 题材活跃（游资接力）
防御强（避险） → 科技弱（杀估值）→ 红利护盘（指数失真）
周期强（资源） → 商品涨价/PPI 上行 → 通胀预期
```

### 与市场阶段对应

| 市场阶段 | 领涨大类 | 策略 |
|---|---|---|
| 牛市中段 | 科技成长（进攻）| 趋势跟踪主线 |
| 牛市末端 | 券商（大金融）| 顺周期+情绪 |
| 熊市初期 | 公用/红利（防御）| 减仓避险 |
| 熊市末期 | 大消费（防御）| 底仓消费 |
| 磨底期 | 周期（资源）| 超跌反弹 |
| 题材期 | 题材/主题 | 快进快出 |
