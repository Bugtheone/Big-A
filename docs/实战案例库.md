## 案例一：F档缩量预警 → 大跌兑现（2026-08-17 ~ 08-19）

**背景**：08-17 收盘定格 成交 23875 亿 < 2.5 万亿、广度 43.7%、涨停 54 家 → position_sizer 出 **F 档（0%）**；半导体/通信主线资金虽强但量能不达标。

**预判**：F 档报告明示"缩量则高位分支有兑现风险，明日关键=成交能否放大至 2.5 万亿+"。

**实际**：08-18 冲高 3994 逼近 4000 未破 → **08-19 单日 -2.40% 放量长阴**（3979→3894），科技高位分支领跌兑现。

**命中评估**：✅ 预警完全兑现（缩量→兑现风险→大跌），且空仓状态零损失。

**教训/迭代点**：
- 量能门槛（2.5万亿）是有效的前置风控信号——即使主线资金强也不破例
- 该案例成为"60/40 法则作风控用有效"的活体证据

## 案例二：周一三情景预判 → C 情景触发全过程（2026-08-24 · 干跑 Day1）

**背景**：08-21 收盘 上证 3905.20 / 成交 18793 亿 / 广度 43.7% / 涨停 54 → F 档维持；3890 = MA20(3893)+08-19低点(3894) 重合关键支撑。周日预判三情景：**B 缩量横盘 60% / C 放量破位 30% / A 放量反转 10%**，关键分歧点=3890。

### 实际演变时间线（盘中四次快照）

| 时点 | 上证 | 广度 | 成交(累计) | 判定 | 系统动作 |
|---|---|---|---|---|---|
| 09:35 | 3906.86 (+0.04%) | 50.6%（回升） | 2529亿 | A/B 边界 | 不动作（未触发）✓ |
| 09:48 | 3894.98 低3888 | 35.4%（崩） | 5538亿 | **C 触发**（破3888+放量） | 风控升级·禁抄底 ✓ |
| 10:02 | 3885.44 低3882 | 21.9% | 7570亿 | **C 确认加深**（现价稳在3890下） | 维持空仓防守 ✓ |
| 11:15 | **3878.41 (-0.69%)** 低3867 | 21.3%（极端普跌） | 13127亿（折算全天≈3.4万亿恐慌级） | **C 完全确认+加深** | 空仓锁定·午后剧本三线 |

**午前要点**：MA20(3893)/3890 双双失守；创业板 -3.34%/科创50 -3.36% 领跌（科技杀）；历史级放量长阴（半日1.3万亿）；资金避险流向锂矿/破净股/红利。

### 命中评估

| 预判项 | 实际 | 结果 |
|---|---|---|
| 三情景概率排序 B>C>A | C 兑现（概率第二命中） | ⚠️ 方向对·权重偏 B |
| 3890 为关键分歧点 | 盘中破至 3888→3885→3882 | ✅ 精确 |
| "若 C 触发下看 3800/3858" | 盘中最低 3867（距3858一步） | ⏳ 进行中 |
| F 档空仓纪律 | 全程无买入动作 | ✅ 零损失 |

### 午后时间线与收盘定性（20:47 补录）

| 时点 | 上证 | 事件 |
|---|---|---|
| 13:11 | 3871.46（创业板新低3400） | 续跌无反抽·主线剧本概率上调85% |
| 14:13 | 低点 **3855.35** | **3867/3858 双双击穿，加速线触发** |
| 15:00 收 | **3882.01 (-0.59%) 广度25.5%** | **缩量止跌+尾盘承接修复，长下影27点** |

**收盘定性：真破位成立 ✅ 但未加速 ✗ =「缩量探底+初步承接」**

1. 真破位 ✓：收盘 3882 < 3890 < MA20(3893)，破位状态维持（连续两日收于MA20下方）
2. 未加速 ✓：3855 获承接收回 3858 上方；午后90分钟仅成交2846亿明显缩量
3. 全天成交 20075亿（vs 昨18793亿仅 +6.8%）——**量能定性修正：非恐慌宣泄日，是缩量探底日**
4. 剧本命中：主线剧本"弱收3870-3890真破位"(70%)精确命中收盘区间3882

### 教训与迭代点（供 v2.1 参考）

1. **情景概率应动态修正**：09:35 广度回升 50.6% 曾让 A 概率上升，13 分钟后崩至 35.4%——早盘前 30 分钟的广度/量能信号噪声大，**情景判定应以 10:00 后数据为准**（写入流水线规则）
2. **C 情景的确认标准已验证有效**："放量+现价持续在支撑下方（非瞬时假破位）+广度恶化"三条件同时成立才确认——本次 09:48 触发→10:02 确认的两步法避免了一次假信号追杀
3. **反抽预期管理**：祖训"暴跌次日有反抽，但反抽不是反转"——明日（08-25）若有反抽，按纪律只观察不参与（除非放量收复 MA20=3893 才重新评估）
4. **干跑流程验证通过**：real_time 时间戳校验/双源交叉/介入点工具化全部执行到位
5. **🔴 盘中成交折算必须按时段权重修正**：14:13 按17228亿线性外推"全天≈3万亿恐慌级"，实际收盘仅20075亿（+6.8%）——早盘恐慌段占全天成交比重高，午后缩量使线性外推严重高估。修正规则：**折算值只作区间参考（±20%标注），量能定性以收盘官方值为准**；本例若据此在午后误判"恐慌宣泄进行中"而提前抄底，将买在加速段
6. **确认即行动条款首战生效**：09:48 确认价 3894.98 vs 收盘 3882.01，迟疑成本 0.33%——持仓者按五·0 条款即时减仓优于等收盘
