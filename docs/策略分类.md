## 一、策略五大流派总览

| # | 流派 | 逻辑 | 主要工具 | 优点 | 缺点 | 适用环境 |
|---|---|---|---|---|---|---|
| ① | **趋势跟踪** | 市场有惯性，强者恒强 | 均线系统（MA5/10/20/60）、MACD、SAR、通道突破 | 吃主升浪；牛市收益最高 | 震荡市反复止损 | **主线持续性行情** |
| ② | **均值回归** | 涨多必跌、跌多必涨，围绕均值波动 | BOLL 轨道、RSI 超买超卖、偏离度（现价 vs MA）| 震荡市收割波段；入场早、胜率高 | 单边趋势接飞刀 | **震荡/横盘市** |
| ③ | **突破交易** | 突破关键位确认新趋势 | 平台突破、唐奇安通道、N日新高、涨停突破 | 趋势启动第一时间介入；爆发力强 | 假突破多（需量验证）；追高成本高 | **放量突破+主线确认** |
| ④ | **事件驱动** | 利用事件信息差（业绩/重组/政策）| 业绩日历、公告、龙虎榜、中报预期差 | 与市场低相关；确定性高 | 信息时效短；踩雷风险 | **中报季/事件窗口** |
| ⑤ | **价值/成长** | 买低估或买高增长，长期持有 | PE/PB 分位、ROE、净利润增速 | 安全边际高 | 持有周期长；估值陷阱 | **估值分位<20% 的持续分支** |

## 二、各流派详细定义与判定标准

### ① 趋势跟踪（主策略）
- **确认条件**：指数站上 MA5/MA10/MA20 且 MA 向上（金叉）；主线板块资金持续流入 ≥3 日
- **持仓**：趋势未破（收盘不破 MA10/MA20）前持有
- **退出**：破 MA10（短线）/ 破 MA20（波段）/ E 信号触发
- **T-score 趋势量化（2026-08-06 工程化）**：`trend_tracker.py --codes XX` 六因子 0~100 分

| T-score | 状态 | 动作 |
|---|---|---|
| ≥80 | 🟢🟢 强多头 | 主升持有 |
| 65~79 | 🟢 多头 | 持有 |
| 50~64 | 🟡 震荡偏多 | 回踩介入 |
| 35~49 | 🔴 偏空 | 减仓 |
| <35 | 🔴🔴 空头 | 空仓 |

**六因子**：MA排列(25) + 价格位置(20) + 均线斜率(15) + 回撤深度(15) + 动量ROC(15) + 量能配合(10)
- 案例（08-06）：工业富联 T=52 震荡偏多（回踩介入）· 胜宏 T=44 偏空 · 浪潮 T=18 空头
- 本体系映射：**只做持续性主线**（交易哲学）、主线五条件（涨幅/资金/涨停/连板/逻辑）

### ② 均值回归（回踩介入）
- **核心指标**：偏离度 = (现价 - MA10) / MA10
- **分级标准**（entry_point.py 内建）：

| 偏离度 | 状态 | 动作 |
|---|---|---|
| -3% ~ +3% | 🟢 真回踩 | 可介入区（0.5~1% R 试错）|
| +3% ~ +8% | 🟡 偏离偏大 | 等回踩，不追 |
| > +8% | 🔴 急拉超买 | **严禁追高** |
| < -3% | 🟡 均线下方 | 趋势未走强，观察 |

- **Q-score 回踩质量评分（2026-08-06 工程化）**：六因子加权 0~100 分，`entry_point.py --codes XX` 自动输出

| Q-score | 分级 | 动作 |
|---|---|---|
| ≥80 | 🟢🟢 **A级 强回踩** | 1% R |
| 65~79 | 🟢 **B级 标准回踩** | 0.5~1% R |
| 50~64 | 🟡 **C级 弱回踩** | 观察 |
| <50 | 🔴 **D级 不介入** | 放弃 |

**六因子权重**：偏离度(30) + 缩量(20) + 回踩天数(15) + RSI(15) + MA结构(10) + 量价形态(10)
- 全部因子仅用腾讯官方日K计算（无估算）；量能 = 当日量/5日均量（同源）
- 案例验证（08-06）：中科曙光 Q=75 B级 · 浪潮 Q=79 B级 · 富联 Q=52 C级 · 胜宏 Q=44 D级（急拉超买标的自动降级）

- **辅助确认**：量比 <0.8（缩量企稳）、MACD 不恶化、板块资金未转流出
- **止损**：MA10 × 0.95（破位止损）/ -5% 硬止损

### ③ 突破交易
- **确认条件**：放量（>5日均量 1.5 倍）突破前高/平台 + 主线确认 + 炸板率 <15%
- **禁用**：炸板率 >15%、冲高回吐（如 08-06 上午 +0.88%→-0.04% 的假突破）
- **验证**：突破后 2~3 日不回落 = 真突破；回落 = 假突破离场
- **B-score 突破量化（2026-08-06 工程化）**：`breakout_detector.py --codes XX` 六因子 0~100 分

| B-score | 分级 | 动作 |
|---|---|---|
| ≥75 | 🟢🟢 A级 真突破 | 可追 |
| 60~74 | 🟢 B级 有效突破 | 回踩介入 |
| 45~59 | 🟡 C级 弱突破 | 观察 |
| <45 | 🔴 D级 假突破/追高 | 禁止 |

**六因子**：突破幅度(25) + 量能爆发(25) + 平台整理(15) + 趋势方向(15) + 回踩确认(10) + 位置安全(10)
- 案例（08-06）：富联/胜宏/浪潮 B=10~24 全部 D 级（回撤环境无真突破 = 防守正确）

### ④ 事件驱动
- **事件日历**：业绩预告（7月）→ 中报（8月）→ 业绩快报 → 分红/送转
- **预期差核心**：实际 > 预期 = 超预期（买）；实际 < 预期 = 不及预期（避）
- **工具**：`midreport_tracker.py`（披露计划+预期差+一致预期）、`earnings_forecast.py`（预增+主线标记）
- **验证案例**：08-06 中报季——工业富联预增 93~101%、中微公司预增 282~310% 为主线内优选

### ⑤ 价值/成长
- **估值分位**：PE/PB 近 250 日分位（`tech_indicators.py`）
- **分级**：<20% 低位🟢 / 20~80% 中位 / >80% 高位⚠️
- **优选逻辑**：资金流入 + 估值分位低 + 技术转好 = 三维共振（如 08-06 胜宏科技 PE 分位 3.6% + 资金+17.5亿 + MACD金叉）

### ⑥ 资金流/情绪策略（本体系核心特色）
- **C/D/E/F 信号体系**（strategy_signal.py）：

| 信号 | 含义 | 判定 |
|---|---|---|
| C1 | AI 算力 3 连阳 | 涨停≥30 + CPO 领涨 |
| C2 | 广度≥60% | 涨家数≥3500 |
| C3 | 上证50 翻红 | 指数快照 |
| C4 | 连板晋级 + 炸板率<15% | 打板池 |
| D1 | 中军续涨 | 旭创/协创/新易盛/富联均值 |
| D2 | 中军杀跌 | 中军均值<0% → 减仓预警 |
| E1 | 广度<55% | **冻结新仓** |
| E2 | 涨停断层<60 | **反弹结束，清仓** |
| E3 | 上证破5日线 | **全面防守** |

- **优先级铁律**：**撤退信号（E）> 升级信号（C）**；D2 中军预警 > C 系升级

#### ⑥补充·外部参考对照：抖音"全能的野人"情绪周期系统（2026-08-17 整理）

> 完整对照图见 `docs/野人vs炒股三句话_对照图.md`。来源：网络公开信息（雪球/东财/同花顺/微博摘要，未经官方证实）。

- **野人核心**：纯情绪周期择时——①盘面情绪五维（量能/涨跌停/龙头/赚钱效应）②前一日涨停次日晋级率 ③连板高度 ④冰点→高潮周期（冰点埋伏/高潮止盈）⑤股债收益率对比辅助估值
- **与⑥同向（可吸收）**：量能+涨停+龙头择时共识；高潮减仓 ≈ E 信号；冰点埋伏 ≈ 超跌反弹策略；"慢就是快/保住本金" ≈ 纪律性持有
- **与⑥差异（本体系立场）**：
  1. 野人纯情绪，本体系强制"逻辑硬"（政策/产业/预增验证）+ 资金连续 3 日验证——纯情绪无逻辑 = 核电式一日游（13→5→0 家实测）
  2. 野人主模式为打板/接力，本体系轮动期打板实测否决（08-12→13 平均 -8.62% 胜率 1%；08-13→14 平均 -10.25% 胜率 0%）
  3. ⚠️ 野人存在"抢帽子"操纵市场网络举报（2026-06-11 东财帖，未证实）——外部主播带票一律走三查清单（主营/业绩/历史）再决定
- **定位**：野人给"情绪周期心法"，本体系给"情绪周期的量化执行"——方向一致，用实测数据+资金/逻辑验证落地为可执行规则

### ⑦ 仓位管理（60/40 法则）
- **可操作条件**：成交 ≥2.5 万亿 **且** 指数站上 5/10 日均线（双满足）
- **档位**：观望 0% → 试错 ≤10% → 升级 20~40% → 主升 40~70%
- **深度约束**：广度 <55%（E1）冻结新仓；破 30% 抱团松动，主线减仓
- **自动化（2026-08-06 工程化）**：`position_sizer.py` 自动拉取市场数据（盘中成交按已交易时间折算全天），输出档位映射

| 档位 | 总仓上限 | 触发条件 |
|---|---|---|
| F 观望 | 0% | 成交折算 <2.5万亿 或 指数破 5 日线 |
| E 防守 | ≤10% | E1/E2/F1 任一触发（仅 0.5~1% R 试错）|
| D 试错 | ≤20% | 无拦截 + 1 信号 |
| C 升级 | 20~40% | 2 信号（广度60%+涨停60+成交3万亿+）|
| B 加仓 | 40~70% | 3 信号 |
| A 主升 | 70~100% | 4 信号全满足 |

- 案例（08-06 11:33）：成交折算 3.5万亿 + 广度 28.4% + 涨停 58 → **档位 E 防守（≤10%）**——与撤退纪律一致

## 三、策略选择路由（按市场状态）

> **自动化（2026-08-06 工程化）**：`scripts/market_router.py` 实现设计方案 v1.0——Gate 门控 → 行情类型（12种）→ 策略路由 → 板块方向 → 仓位计算，一键输出每日决策报告。设计文档：`docs/行情策略路由引擎_设计方案.md`。
> 实测（08-06 11:39）：结构性+超跌反弹+抱团行情 → 顺势波段/抱团核心/修复段轻仓 → 仓位 0%（E 档）

```
市场状态判定（60/40 法则 + 信号体系）
        │
        ├─ 单边下跌（E1/E2/E3 触发）→ 【防守】空仓/清仓，只观察池
        │
        ├─ 震荡市（广度 40~60% 波动 + 无持续主线）
        │      → 【均值回归】BOLL 上下轨高抛低吸 + 情绪信号快进快出
        │
        ├─ 主线启动（放量 + 主线确认 + 广度 55%+）
        │      → 【趋势跟踪】主线持仓 + 回踩加仓（均值回归辅助）
        │
        ├─ 突破确认（放量突破 + 炸板率<15% + 主线不降级）
        │      → 【突破交易】第一时间介入前排核心
        │
        └─ 事件窗口（中报/预告/重组密集期）
               → 【事件驱动】预期差选股 + 事件日历
```

### 当前市场路由（2026-08-06 示例）

```
广度 28.9%（<55% E1 触发）· 涨停 57（<60 E2 触发）· 炸板率 23.3%
→ 路由：单边下跌档 → 【防守】空仓/清仓
→ 均值回归等待中：富联/胜宏 等回踩 MA5/MA10（不追 +16%/+20% 偏离）
→ 事件驱动持续：中报季富联预增 93~101% 已兑现
```

## 五、策略纪律红线（所有流派通用）

1. **撤退优先**：E1/E2/E3 任一触发 → 撤退/清仓，不论其他策略信号
2. **介入点官方K线**：介入点/止损位一律 `entry_point.py` 计算，禁止估算
3. **止损铁律**：-5% / 破 MA10 无条件离场，不补仓
4. **T+1 纪律**：今日买入明日处理，止损 -5%
5. **单笔风险**：0.5~1% R（熊市档减半），总仓按市场档位
6. **数据真实**：所有数字必须来自数据源工具输出，可追溯，禁编造
