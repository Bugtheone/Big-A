# AI 数据约束手册（防止幻觉/编造/过时数据）

> **版本**：2026-08-05 v1.0｜**目的**：约束 AI agent 只从本项目真实数据源取数分析，产出可追溯、可验证、实时的结论
> **适用**：所有 AI 对话、子代理、调度任务

---

## 一、核心原则

> **把"AI 可信"变成"系统可信"**——数据获取从"AI 自由发挥"改为"机器固化产出 + API 强制取数"，AI 只做分析不碰原始数据获取。

```
┌─ 第1层 输入侧：只给数据源这扇门（禁 web 搜索/网页抓取）
├─ 第2层 处理侧：数字必须可追溯（禁记忆写数/交叉验证/新鲜度）
├─ 第3层 输出侧：结论带来源+时间戳（报告模板强制验证章节）
└─ 第4层 工程侧：机器兜底（deny 规则/hooks/脚本产数据 AI 只读）
```

## 三、硬性纪律（违反即分析无效）

### 3.1 数据获取
1. **禁止** web 搜索/网页抓取代数（config.toml 已 deny：WebSearch/WebFetch/WebBrowse/Browser + curl google/baidu/bing）
2. **禁止** 凭训练数据/记忆写行情数字——**每个数字必须来自工具输出**
3. **禁止** "网上看到的/我记得/大约"充当数据
4. 数据源不可用 → 显式标注降级链，**禁止用记忆补数**

### 3.2 交叉验证
5. 关键结论（指数/成交/涨停/主线）**必须 ≥2 源交叉验证**
6. 跨源不一致 → 标注 `⚠️跨源差异` + 说明权威源取舍
7. 盘中数据带时间戳；**>15 分钟未刷新标 `⚠️stale`**
8. 盘后（Tushare 17:00 后）vs 盘中定格（腾讯）误差 >0.3pt → 复核

### 3.3 输出
9. 报告必须含**"数据源验证"章节**（指标/源A/源B/结果表）
10. 关键数字标注来源：`上证 3871.65（腾讯 11:21 快照）`
11. 数据缺失/降级/异常**显式声明**，禁止静默忽略

### 3.4 生产链路
12. 盘中调度 → 脚本机器拉数 → 写 `reports/daily/<date>/*.md`
13. AI 分析基于**固化数据文件 + API 调用**，不自行发明
14. 新数据需求 → 调用 `api.xxx()`/`gate.xxx()` 或跑 `intraday_enhance.py`

## 四、自查清单（AI 输出前必查）

- [ ] 数字能否追溯到工具输出？不能 → 重做
- [ ] 是否用过 web 搜索取数？用过 → 数据无效
- [ ] 行情数据有时间戳吗？没有 → 标 stale
- [ ] 关键结论双源了吗？没有 → 降级"单源参考"
- [ ] 数据源降级声明了吗？没有 → 补声明


## 六、机器保障（不靠 AI 自觉）

| 手段 | 配置/位置 |
|---|---|
| 禁 web 搜索 | `~/.grok/config.toml` [permission] deny（WebSearch/WebFetch/curl 搜索引擎）|
| 数据路由 | `AGENTS.md`（MCP/技能/数据源规则 + AI 数据纪律章节）|
| 自动拉数 | crontab 18:00 复盘 + Grok 调度 15 分钟快照（intraday_snapshot→sector_delta→strategy_signal→intraday_enhance）|
| 交叉验证 | `scripts/verify_a_stock_data_v360.py`（CI 门禁）|
| 数据守门 | `scripts/data_gate.py`（gate 封装）|
