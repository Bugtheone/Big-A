## 二、市场情绪判断五大维度（✅ 雪球转载标注"博主：全能的野人"）

1. **大盘量能 + 涨跌/涨停数量 + 龙头表现 = 整体盘面情绪**
   - 向好信号：普涨、成交量持续放大、情绪龙头持续走强、整体有赚钱效应 → 适合进场
   - 转弱信号：成交量逐步萎缩、赚钱效应下降 → 及时减仓甚至空仓
   - **特殊缩量行情：缩量但盘面普涨 = 空方力量衰竭 → 可逢高分批减仓**
2. **前一日涨停股次日表现**（晋级率/溢价）：打板情绪的直接温度计
3. **龙头表现**：情绪龙头强弱定盘面情绪
4. **情绪周期定位**（见下节）
5. **股债收益率对比（估值辅助）**：股票收益率远高于国债 = 极度悲观 ≈ 便宜（底部信号准确率高）；两者接近 = 乐观追高 ≈ 贵（顶部警惕）——指标走到历史极端 = 情绪到头

## 三、情绪周期分阶段（📋 游资圈通用框架，其连麦/转载内容与之一致）

### 3.1 阶段划分（东财财富号"情绪周期与节点转换"篇）

> 注：同文被溯源至淘股吧"米开朗基瑞"（2025-01-31），属圈内共享方法论；野人直播/连麦多次讲同一套，故列入其体系。

1. **前提**：资金情绪都在**涨停板和跌停板**上——做情绪/周期分析只看涨跌停数据
2. **题材周期分阶段**：
   - **1阶段（启动）**：1~4 板，小弟 1 助攻
   - **2阶段（主升）**：3、4 板见 1 阶段**分歧**，经历首次分歧后**弱转强**加速进入主升，一般 4~7 板，小弟 2 助攻
3. **节点转换铁律**：老龙头断板出补涨、老龙头跌停出新周期——周期切换的"天时"

### 3.2 情绪周期完整循环（圈内标准四/五阶段）

```
冰点期 → 启动期（试错）→ 发酵期（主升）→ 高潮期 → 退潮期 → 冰点期（循环）
```

| 阶段 | 特征 | 应对（📋 圈内通用） |
|---|---|---|
| 冰点期 | 涨停少、连板高度低（2-3板）、跌停多、亏钱效应弥漫、昨日涨停闷杀 | 轻仓试错/埋伏修复，**不空仓但不满仓**；情绪冰点低吸博弈次日反转 |
| 启动期 | 新题材/龙头试盘、首板增加、跌停减少、空间出现4板 | 试错仓 30~50%，优先换手充分的二板/首板，**回避缩量加速板** |
| 发酵期（主升） | 龙头确认、补涨梯队（小弟2助攻）、题材连续领涨、最容易出妖股 | **上仓位的关键期**，聚焦最主流热点龙头，做持续分支 |
| 高潮期 | 龙头缩量加速、补涨批量涨停、板块成交占比飙升、情绪亢奋 | **止盈减仓防守**；高潮日次日接力=接盘（高开低走概率大） |
| 退潮期 | 家数衰减、高标断板、杂毛占高位、亏钱效应回归 | **空仓保平安**；断板日无条件走 |

## 四、选股：天时、地利、人和（📋 雪球"情绪周期全解"篇，与其直播观点一致）

- **天时**：踩准周期切换的时间窗口——"老龙头断板出补涨，老龙头跌停出新周期"；新题材/新标的是否能走出来，时机 > 个股
- **地利**：题材/板块在周期中的位置（发酵期做主线、冰点期做修复）
- **人和**：龙头股（情绪龙头定方向，紧盯龙头）

---

## 五、买卖点与执行纪律（✅+📋 混合）

- **只做系统内确定性买点**：情绪冰点低吸博弈反转 / 发酵期回踩低吸 / 高潮期不追
- **节点买卖点**（📋）：
  - 趋势转折点：趋势领涨核心首次力竭后的反转日首板——当日平铺首板或次日 1 进 2
  - 首次连板冰点晋级率高 = 情绪修复信号
- **执行**：严格按系统执行，克服人性（连麦强调）；情绪差时空仓也是操作
- **禁止**：无确定性的反弹不参与（哪怕踏空主线）；高潮日追高；无纪律的仓位
